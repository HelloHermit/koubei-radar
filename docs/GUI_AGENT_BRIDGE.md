# 可选：用 GUI 智能体替你翻外卖列表，再导入口碑雷达

> 这是**开发者/高级用户的可选桥接方案**，App 本身不依赖它。
> 风险提示：外卖平台的服务条款可能限制自动化操作；Open-AutoGLM 项目自己声明"仅供研究和学习使用"。请只在**自己的设备、自己的账号**上使用，并保留人工确认。登录、验证码、支付一律由你本人接管，不要让智能体碰支付。

## 思路

```
电脑 + ADB + Open-AutoGLM ──驱动──► 你的手机（美团外卖/饿了么）
        │ 输出：看到的店铺列表文字
        ▼
复制文字 ──► 口碑雷达「导入」页 ──► ShopImportExtractor（LLM 抽取）──► 候选池 ──► 打分筛选
```

GUI 智能体负责"点点翻翻"，口碑雷达负责"判断口碑"。两者之间只用**文字**交接，所以不依赖任何私有接口。

## 步骤

1. 按 [Open-AutoGLM 的 README](https://github.com/zai-org/Open-AutoGLM) 配好 ADB、手机开发者选项与模型端点（自部署 AutoGLM-Phone-9B，或智谱 BigModel / ModelScope 的 `autoglm-phone`）。具体命令以该仓库当前 README 为准。
2. 在手机上先**手动登录**美团外卖/饿了么并设好收货地址。
3. 给智能体一个只读任务，例如：

   > 打开美团外卖，在首页浏览前 20 家店铺（滑动 2–3 次）。不要点进下单页，不要加购，不要支付。逐家记录：店名、评分、月售、起送价、配送费、预计送达时间、人均价格（如有）、标签。最后用「店名 | 评分 | 月售 | 起送 | 配送费 | 送达分钟 | 人均 | 标签」每行一家的格式输出。

4. 把输出文字粘贴到口碑雷达的「导入」页，点「识别」→「加入候选池」。
5. 回到「推荐」或「智能体」页，候选池里已经带上了月售、配送时间等外卖特有信息。

## 为什么不把它做进 App

- 需要电脑 + ADB 或额外的无障碍/悬浮窗权限，普通用户门槛高；
- 自动化操作第三方 App 的合规边界不清晰；
- 模型调用成本高（每步一张截图）。

端侧版本（无障碍服务）在路线图里，前提是"用户本机、本人账号、人工确认"。可参考 Mobilerun 的 Portal 应用与 OpenGUI 的做法（注意 OpenGUI 为 BUSL-1.1 许可）。
